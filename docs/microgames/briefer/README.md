# Briefer for mikrospill

Én fil per spill (`<id>.md`), skrevet av nattsporet før det koder. Hver fil har tre seksjoner:

- `## Konseptturnering` - fem vidt forskjellige konsepter, dommerens poeng og vinneren
- `## Designbrief` - de ti punktene i steg 2b i `.agent/workflows/build_microgame.md`
- `## Kunstbrief` - looken, hentet fra emnets egen bildekultur (steg 2c)

Selvspillet (`scripts/playtest-microgame.mjs`) krever fila for alle nye spill. Den er også
hukommelsen til generatoren: neste natt leser de siste briefene for ikke å gjenta sjanger,
perspektiv eller kunstretning.
