# Referansebilder for mikrospill

Kalibrering for den uavhengige vurderingen (port 3 i `.agent/workflows/build_microgame.md`).
Bildene er tatt av `scripts/playtest-microgame.mjs` (startskjerm, filmstripe av vinnerroboten,
slutt-skjerm) for de to referansespillene:

- `havet-kommer-*` - Havet kommer (2D, Doggerland)
- `stavkirken-3d-*` - Regnet i Lærdal (3D, stavkirker)

Rekalibrert 2026-09-28: eieren syntes Regnet i Lærdal var «interessant, men ikke sinnsykt gøy».
Begge er derfor 3 på Gøy, 4 på Lesbart og 5 på Lærerikt, og 3 (Havet kommer) og 4 (Regnet i
Lærdal) på Utseende. En 4 på Gøy betyr klart gøyere enn disse. Ta bildene på nytt hvis
referansespillene endres mye.
